🧱 Brick Breaker Game (Java Swing)
📌 Overview
This is a basic Brick Breaker game developed in Java using the Swing framework. It was created as a learning project to strengthen my understanding of core Java, particularly in GUI application development using Swing components, event handling, and rendering custom graphics.
Through this project, I have gained hands-on experience in:

How Java Swing and its components (like JPanel and JFrame) work.
Handling user input using KeyListener.
Creating game loops using javax.swing.Timer.
Performing simple collision detection and game state updates.

🧠 Key Learnings
Java Swing: How to use Swing to build GUI-based applications.
Graphics Rendering: Drawing the paddle, ball, and game background manually using the paint(Graphics g) method.
Keyboard Input: Implemented paddle control using the left and right arrow keys with KeyListener.
Game Logic: Created a real-time game loop using Timer and managed ball movement, collision, and basic interactions.
